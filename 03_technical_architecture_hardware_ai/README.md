# Technical Architecture, Hardware, and AI — `EF-TEC`

This directory preserves historical alternatives, stack proposals, data/AI reasoning, hosting considerations, and hardware/sensor research. It records option space and technical rationale rather than a finalized architecture.

`EF-TEC-005` is the preferred parseable historical sensor-research record. Earlier FireShot/text variants remain raw-provenance aliases and are not normal retrieval sources. `EF-TEC-007` is complementary alternatives research. None of these files qualifies a component, supplier, price, RF design, calibration method, safety case, or field outcome for current deployment.
