# Start Here — EcoFarm Archives

This folder is the **navigation layer** for the public EcoFarm archive. It contains no primary `EF-*` evidence and does not replace the archive’s canonical source paths. Its purpose is to help a human reader or an AI agent choose the right entry point before opening the underlying knowledge materials.

| If you need to… | Open this first | Then continue to… |
|---|---|---|
| Understand the whole project and its preserved reasoning | [Master Knowledge Base](../10_knowledge_base_outputs/EcoFarm_Master_Knowledge_Base.md) | The linked canonical `EF-*` source records for the topic in question. |
| Browse visually | [HTML Knowledge Site](../10_knowledge_base_outputs/html_knowledge_site/index.html) | The Source Catalogue or Evidence Atlas page within the site. |
| Ask an AI agent a precise question | [LLM Agent Handoff](LLM_AGENT_HANDOFF.md) | The LLM corpus guide, Evidence Atlas, and referenced sources. |
| Check what an assertion actually supports | [Evidence Atlas](../10_knowledge_base_outputs/evidence_atlas/README.md) | The cited source record and, when required, a current primary source. |
| Locate a particular reviewed record | [Curated Archive Index](../CURATED_ARCHIVE_INDEX.md) | The category directory and file named by its `EF-*` ID. |
| Understand curation, provenance, or publication controls | [Metadata Guide](../archive_metadata/README.md) | The specific register or audit record. |
| Rebuild or maintain the archive | [Infrastructure Guide](../archive_infrastructure/README.md) | The named generator or validation script. |

> **Reading rule:** Archive inclusion preserves information; it does not validate a claim. Historical intent, research design, secondary synthesis, field instruments, visuals, and current primary evidence have distinct authority.

## What is canonically stable

The ten numbered source-category directories at the repository root contain the canonical reviewed `EF-*` files. Their paths are retained deliberately so that source links, retrieval records, and GitHub citations remain stable. This `00_START_HERE` folder is additive navigation only.

## Recommended reading paths

The [Human Reading Path](HUMAN_READING_PATH.md) is suitable for a founder, researcher, collaborator, or reviewer. The [LLM Agent Handoff](LLM_AGENT_HANDOFF.md) is suitable for an agent with file and web access that must answer questions without flattening the archive’s evidence boundaries.
