# Governance and Archive Records — `EF-GOV`

This directory contains the **current archive rules, founder instructions, approvals, and research-programme handoffs** that govern how EcoFarm material is handled. These records control archive method and evidence discipline; they are not agricultural, market, technical-feasibility, or field-validation evidence.

Use the [Curated Archive Index](../CURATED_ARCHIVE_INDEX.md) to find a specific `EF-GOV-*` record. For evidence treatment across all families, consult the [Evidence Atlas](../10_knowledge_base_outputs/evidence_atlas/README.md).
