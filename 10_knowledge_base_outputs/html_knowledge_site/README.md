# EcoFarm HTML Knowledge Base

Open `index.html` in a modern browser, or host this directory with any static server. The site has 16 linked pages, client-side search, and a curated source catalogue. Citations in the article pages use category-aware `EF-*` IDs and link directly to canonical GitHub archive files. The catalogue intentionally excludes ordinary app code, dependency/configuration files, generated builds, and duplicate aliases. It is generated from `EcoFarm_Master_Knowledge_Base.md` using `build_html_knowledge_site.py`.
