# Knowledge Base Outputs

This directory contains the archive’s three coordinated knowledge-delivery formats and the Evidence Atlas. These materials are navigation and synthesis layers; the canonical primary sources remain in the ten numbered `EF-*` category directories at the repository root.

| Directory or file | Primary audience | Use it for | Do not use it for |
|---|---|---|---|
| [EcoFarm Master Knowledge Base](EcoFarm_Master_Knowledge_Base.md) | Human readers | Reconstructing vision, working models, feature intentions, research, technical reasoning, alternatives, and unresolved questions. | Treating synthesis prose as a replacement for its cited source records. |
| [HTML Knowledge Site](html_knowledge_site/README.md) | Human readers | Topic browsing, search, source catalogue access, and Evidence Atlas navigation. | Assuming a static page proves the content is current. |
| [LLM Knowledge Corpus](llm_knowledge_corpus/README.md) | LLMs and agents | Structured retrieval, source-span discovery, and recoverable source linking. | Generating final conclusions without consulting evidence labels and sources. |
| [Evidence Atlas](evidence_atlas/README.md) | Humans and agents | Evidence status, relationships, claims, assumptions, contradictions, open questions, and bounded revalidation. | Replacing current primary-source checks for dynamic external facts. |

Start with [`../00_START_HERE/README.md`](../00_START_HERE/README.md) if you are unsure which format to open first.
