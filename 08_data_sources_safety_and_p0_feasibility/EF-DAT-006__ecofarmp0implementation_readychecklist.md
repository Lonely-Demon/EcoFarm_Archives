# EcoFarm P0 Implementation-Ready Checklist

**Use only for:** one human-supervised sowing/early-establishment decision packet. A row marked “block” means no constrained recommendation may be produced until the condition is met.

| Field or control | Minimum requirement | Consent state | Validation rule | Retention / deletion action | Source record | Output state | Referral trigger | Failure behavior | Build gate |
|---|---|---|---|---|---|---|---|---|---|
| Language preference | Farmer selects supported language. | Granted for this decision. | Explicit selection; no silent language inference. | Delete with decision record or change on request. | Farmer-input event with timestamp. | Localized question and limitation text. | Farmer cannot understand the output. | Stop and offer assisted/manual review. | Block if no comprehensible language flow. |
| Village or block | Named target geography. | Granted for this decision. | Controlled list plus confirmation; never treat as exact plot. | Delete with decision record. | Farmer-input event. | Geography-labelled evidence. | Location outside tested scope. | Suppress localized output; show reference-only/referral state. | Block if missing or unmatched. |
| Crop | Named crop. | Granted for this decision. | Controlled list/local-name confirmation. | Delete with decision record. | Farmer-input event. | Crop-matched reference only. | Crop has no reviewed P0 guidance. | No recommendation; show scope limitation. | Block for comparison if missing. |
| Crop stage | Sowing or early-establishment stage. | Granted for this decision. | Explicit controlled stage; no default. | Delete with decision record. | Farmer-input event. | Stage-matched output. | Farmer cannot identify stage. | Reference/referral only. | Block if unknown. |
| Intended sowing window | Specific date or short range. | Granted for this decision. | Valid future date/range within workflow horizon. | Delete with decision record. | Farmer-input event. | Weather validity comparison. | Window falls outside source validity. | Suppress weather prompt. | Block if absent. |
| Water availability | Farmer-selected constraint category. | Granted for this decision. | Reliable/seasonal/rainfed/uncertain/unknown; user confirmation. | Delete with decision record. | Farmer-input event. | Constraint explanation, not water forecast. | Water status uncertain where comparison depends on it. | Mark incomplete; refer/manual review. | Block for crop-option comparison; not raw reference. |
| Farmer objective | Named trade-off such as water conservation or timing flexibility. | Granted for this decision. | Select one/more goals; no implied profit maximization. | Delete with decision record. | Farmer-input event. | Explain trade-offs. | Objective cannot be stated. | Informational view only. | Block for comparative output. |
| Soil report value | Use only if needed for selected comparison. | Separate explicit consent or documented owner permission. | Report date, units, value range, and original reference. | Retain shortest practical period; delete raw and derived values on request. | Report reference and consent event. | Constraint evidence. | Stale/missing/incomparable test. | Exclude soil factor; never substitute district average silently. | Permission-dependent. |
| Weather/advisory record | One selected official source record. | No farmer consent needed for public source, but source rights must permit use. | Source, issue time, valid period, geography, raw reference, retrieval time, and rule version. | Retain audit snapshot separate from farmer identity where possible. | Immutable source/freshness/transformation logs. | Informational/caution/refer only. | Stale, empty, malformed, unauthorized, mismatch, conflict, or unverified transform. | Fail closed; show unavailable/conflict state. | **Currently blocked: selected TNAU path fails Namakkal locality and rights approval.** |
| Guidance reference | Exact crop/stage/revision citation. | No farmer consent; source reuse rights required. | Crop, region, stage, version, source URL, reviewer. | Retain citation/version. | Reference record and reviewer identity. | Manual-reference explanation. | No matching guide or rights uncertain. | Link/reference only; no transformed rule. | Manual-only until permission/review. |
| Market context | Optional; only if Agent 1 identifies a decision-relevant crop/market. | Farmer choice to request it. | Exact market, commodity, variety, grade, unit, date, and freshness. | Delete decision link on request; preserve non-personal source audit as lawful. | Raw query/response and semantic validation. | Raw observation with full caveat. | Any semantic/freshness/rights mismatch; no decision relevance. | Exclude market context. | Not in P0 until crop/market and relevance pass. |
| Source attribution | Visible for every source-derived item. | Not applicable. | Publisher, URL/reference, issue/retrieval time, valid period/date, geography, freshness, limitation. | Retain in output log. | Output/source link. | Source-labelled output. | Any attribute missing. | Suppress source-derived item. | Block. |
| Farmer response | Optional acceptance/rejection/change feedback. | Separate evaluation consent. | Controlled response plus optional reason. | Delete on request; do not affect access to tool. | Evaluation event. | None required for packet. | No consent. | Continue without collecting. | Not a gate. |
| Referral event | Trigger-specific public directory link/contact. | Notice that referral event is recorded for safety; no need to share other data. | Trigger, wording, date, public link verification date. | Restricted safety log; deletion process stated. | Escalation log. | Neutral no-partnership referral. | High-risk, missing/conflicting evidence, out-of-scope case. | Show public info only; no response guarantee. | Block if referral wording or directory record absent. |

## Pre-build gate

A narrow pilot build may begin only when the farmer-input, consent, deletion, source-log, suppression, and referral controls have been tested end to end. A source-derived weather prompt remains blocked until a source passes the P0 operational tests. The selected TNAU public bulletin did **not** pass target-locality or rights/reuse checks in the executed test; a pilot may therefore proceed only as a human-reviewed context/manual-reference packet unless a different source is separately tested and approved.
