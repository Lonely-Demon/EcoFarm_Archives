# Data Sources, Safety, and P0 Feasibility — `EF-DAT`

This directory contains the P0 controls for data provenance, source semantics, consent, feasibility, escalation, observability, and bounded test evidence. It is the main constraint layer for interpreting data-enabled EcoFarm ideas.

These records govern how a source or feature must be tested; they do not prove that any provider is current, API-accessible, complete, safe for all uses, or ready for product integration.
