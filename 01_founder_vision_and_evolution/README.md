# Founder Vision and Evolution — `EF-VSN`

This directory preserves historical onboarding documents, detailed drafts, outlines, and later summaries of EcoFarm’s vision. It is the main record of **what the project was imagined to become**, how scope changed, and which feature models or mental frameworks were considered.

Treat these files as historical intent and product hypotheses, not as proof of implementation, user demand, data availability, technical safety, or current strategic priority. Use the [Evidence Atlas](../10_knowledge_base_outputs/evidence_atlas/README.md) for version relationships and limitations.
