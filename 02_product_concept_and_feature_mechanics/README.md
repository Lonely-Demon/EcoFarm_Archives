# Product Concept and Feature Mechanics — `EF-PRD`

This directory contains historical product requirements, interaction flows, wireframes, feature inventories, and MVP trade-off records. It preserves the intended mechanics of the farmer-facing experience and surrounding ecosystem.

These files reconstruct historical feature intent. They do not establish that a capability was built, safe, useful, localized, or ready to prioritize. Cross-check data, safety, and field boundaries through the [Evidence Atlas](../10_knowledge_base_outputs/evidence_atlas/README.md).
