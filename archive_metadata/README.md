# Archive Metadata and Governance Records

This directory holds the **explanatory and control layer** behind the curated archive. It is not a second source library. Canonical project material is stored in the numbered `EF-*` category directories; these files explain how material was selected, related, crosswalked, validated for release, and treated for evidence purposes.

| Need | Primary record |
|---|---|
| Find the canonical path, category, role, and legacy mapping for a source | `curated_source_index.json` and `legacy_to_curated_source_map.json` |
| Understand what was included, excluded, or retained as an alias | `inclusion_exclusion_register.md` and `EcoFarm_Content_Based_Curation_Review_Register.md` |
| Understand version families and semantic supersession | `EcoFarm_Content_Based_Version_Comparison.md` and `EcoFarm_Semantic_Supersession_Review.md` |
| Check source coverage and remaining recovery limits | `EcoFarm_Corpus_Coverage_and_Resolution.md` |
| Review public-release controls | `public_release_audit.md` and `public_release_redaction_log.md` |

> Metadata explains treatment. It does not independently prove a product, agricultural, technical, market, or field claim.
