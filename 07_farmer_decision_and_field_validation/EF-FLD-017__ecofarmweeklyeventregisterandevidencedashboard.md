# EcoFarm Weekly Event Register and Evidence Dashboard

**Purpose:** Maintain one auditable register for all candidate A/B events and a weekly dashboard for governance. This is a blank operational template; no field events have been entered.

## 1. Event register

One row per event. Use participant and event codes only.

| Event ID | Week | Village code | Participant code | Crop | Water | Candidate A/B | Event state | Trigger date/time | Decision date/time | Baseline action | Other advice | Authority complete? | Actual action | Evidence class | Follow-up date/status | Outcome field | Confounders | Safety escalation | Attribution status | Coder |
|---|---:|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |

### Controlled values

- **Event state:** recalled / planned / observed live / document-supported / follow-up confirmed / attribution unresolved.
- **Evidence class:** observed / document-supported / third-party corroborated / self-reported / unknown.
- **Authority complete:** yes / partial / no / not applicable.
- **Follow-up status:** not due / scheduled / completed / unable to contact / declined / unsafe / withdrawn.
- **Safety escalation:** no / yes—field lead / yes—qualified public referral / unresolved.
- **Attribution:** no exposure / attribution unresolved / partial contribution / stronger attribution signal.

Mandatory blockers include: no live event; timing disagreement; recruitment dependence; consent uncertainty; unsafe follow-up; missing authority; missing baseline; missing other-advice record; request for prohibited advice; inability to corroborate outcome; commercial conflict; participant withdrawal; or staff safety concern.

## 6. Weekly governance decision

At the end of each week, select one status for each candidate: **not started; discovery only; live event monitoring; follow-up pending; insufficient evidence; safety-constrained; retrospective fallback; or paused**. Do not use “validated,” “adopted,” “impact,” “winner,” or “MVP-ready” in the weekly register.
